QUICK "WHO CAN DO WHAT" SUMMARY
================================================================================

F1  RESEARCH MEETING SCHEDULER                          (Shakib)
    Any project MEMBER      - view the project's meetings
                            - schedule a meeting (invites the whole team)
                            - connect / disconnect their own Google Calendar
                            - add an existing meeting to their own calendar
    ORGANIZER or OWNER only - edit a meeting
                            - cancel a meeting (removes it from every
                              connected attendee's Google Calendar)
    Everyone invited        - receives MEETING_SCHEDULED / UPDATED / CANCELLED
                              notifications
    Non-member              - blocked (403)

F2  PROJECT RECOMMENDATION SYSTEM                       (Shakib)
    Any signed-in user      - see "For you": published projects ranked by how
                              well they match the user's portfolio
    Never recommended       - projects the user owns, is a member of, or has
                              already applied to
    No special roles. Each user only ever sees their own recommendations.

F3  PROPOSAL QUALITY ASSISTANT                          (Zunaid)
    PROJECT OWNER only      - run the AI analysis on their own proposal
                            - re-analyze at any time
    Everyone else           - the panel is not shown; the API returns 403
    Note: analysis is ADVISORY. It never blocks publishing.

F4  PROJECT ANALYTICS DASHBOARD                         (Zunaid)
    Any project MEMBER      - view progress, task/milestone breakdown,
                              30-day completion trend, collaboration totals
                              and per-member contribution scores
    Non-member              - blocked (403)

F5  ACADEMIC PUBLICATION SEARCH                         (Fahad)
    Any signed-in user      - search OpenAlex; read title, authors, venue,
                              year, DOI, citation count, abstract
                            - filter by year range / open access, sort by
                              relevance, citations or date
                            - copy a DOI, open free full text
                            - add a paper to their own research portfolio
    Signed-out              - blocked (401)

F6  PROJECT REPORT GENERATION                           (Fahad)
    PROJECT OWNER only      - download the PDF progress report
                            - fetch the JSON preview of the same data
    Everyone else           - the button is hidden; the API returns 403

API ENDPOINTS
  GET    /api/recommendations

HOW THE MATCH % IS CALCULATED (no AI)
  skillFit    = sum(importanceWeight x proficiencyStrength) / sum(importanceWeight)
                importance: REQUIRED 3, PREFERRED 2, OPTIONAL 1
                proficiency: EXPERT 1.0, ADVANCED 0.85,
                             INTERMEDIATE 0.7, BEGINNER 0.5
                a skill only inferred from past projects counts 0.6
  interestFit = min(1, evidence / 3)
                evidence weights: declared interest 1.0, education field 0.8,
                engaged project domain 0.7, publication venue/title 0.5
                a hit on the research domain itself counts double
  match %     = round(100 x (0.65 x skillFit + 0.35 x interestFit))
                if a side has no data it is dropped and the other is used alone
  Excluded from candidates: projects you own, are a member of, or applied to.

  NOTE: this feature reads the Module 1 Feature 4 portfolio. With an empty
  portfolio it falls back to signals inferred from projects the user engages
  with, and returns an empty list if there is nothing at all to match on.

  GET    /api/proposals/status

  overallScore, summary, strengths[], and three scored dimensions -

  503 / 429 responses are retried 3 times with backoff.
